# Geo Chat App

AI-powered geo navigation web application.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Google Maps

### Backend
- ASP.NET Core Web API
- SignalR
- OpenAI

---

# Features

- AI chat assistant
- Google map integration
- Route rendering
- Nearby suggestions
- Voice assistant
